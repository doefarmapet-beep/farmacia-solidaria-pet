Privacidade

Este texto é uma informação inicial do protótipo e deve ser revisado pela equipe responsável antes de ser tratado como política de privacidade ou publicado como documento legal.

Dados utilizados

Para criar e manter sua conta, o site solicita nome, telefone, e-mail, data de nascimento e endereço. O Supabase Auth processa os dados de autenticação, e o perfil é armazenado no banco de dados Supabase do projeto.

Finalidade e acesso

Esses dados são usados para disponibilizar as funções de cadastro e perfil do DoeFarmaPet. As políticas de segurança do banco limitam cada usuário à consulta e atualização do próprio perfil.

Segurança e contato

Não compartilhe sua senha. Para solicitar correção ou exclusão dos seus dados, entre em contato com a equipe responsável pelo projeto. Os dados e prazos de contato do responsável devem ser incluídos nesta página antes da publicação definitiva.
